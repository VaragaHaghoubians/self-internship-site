# 12-Month Self-Internship Planner

A small website I made to plan and track my own learning path toward an industrial and operations data analyst role. It breaks one year into monthly topics (Python, SQL, APIs, cloud, ML, IoT) with checklists and a weekly study routine.

Live site: https://varagahaghoubians.github.io/self-internship-site/

## How it is built

- Plain HTML, CSS and JavaScript, no framework
- `generate_docs.py` turns my study notes into the HTML pages in `docs/`
- Hosted with GitHub Pages

## Why I made it

I wanted one place to see what to study each month and to keep myself consistent while finishing my MSc in Data Science at the University of Turin.
